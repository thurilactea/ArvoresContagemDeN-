# ArvoresContagemDeNó

Breve descrição do projeto

Projeto desenvolvido em Java para implementar uma Árvore Binária de Busca e contar a quantidade de nós folhas.

Como a estrutura foi implementada

A estrutura foi dividida em três classes: `Node`, que representa os nós; `Tree`, que realiza a inserção e a contagem de folhas; e `Main`, que testa o funcionamento da árvore. Toda a implementação foi feita manualmente, utilizando recursividade para contar as folhas.
